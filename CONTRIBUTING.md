# Repository maintenance

This repository is maintained by its owner. Public visibility does not grant write access.

The maintainer does not accept unsolicited code contributions at this time. Issues may be used for reproducible bug reports; submitting an issue or pull request does not grant permission to merge changes. Any future contribution requires an explicit maintainer review.

Do not include private MIDI captures, device identifiers, credentials, or unrelated personal data in public reports. Describe the routing, macOS version, app version, expected result and actual result. A minimal synthetic example is preferable.
